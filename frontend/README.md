# stocks frontend

React 19 + Vite 8 + TypeScript 6 SPA (ARCHITECTURE §22). Spring Boot serves the built `dist/` from the same
origin. Node ≥ 22.12.

| Command | What it does |
|---|---|
| `npm ci` | Install from the committed lockfile (carries the §2.2 `openapi-typescript → $typescript` override) |
| `npm run dev` | Vite on :5173, proxying `/api`, `/ws`, `/mcp`, `/v3`, `/swagger-ui` to `localhost:8080` (§24.6). `STOCKS_BACKEND_URL` overrides the target |
| `npm run dev:mock` | Same UI against the in-memory fake API and quote stream (`VITE_API_MOCK=1`, §22.9); no backend needed. Signed in as the admin `demo`; any password except `wrong` works; `/join/welcome-friends` is a valid invite. `VITE_QUERY_DEVTOOLS=1` shows the TanStack Query devtools |
| `npm run build` | Typecheck, then build to `dist/` |
| `npm run lint` / `typecheck` / `test` | oxlint (warnings fail) · `tsc -b` · Vitest (run once) |
| `npm run gen:api` | `openapi-typescript ../docs/openapi.json -o src/lib/api/schema.d.ts` (normally via `make openapi`) |
| `npm run e2e` | Playwright at 390×844, 768×1024 and 1440×900: sign in/out, search, a $25 dollar buy into a position, cancel a resting limit, watchlist add/reorder/remove, admin deposit to ALL, invite signup, AI player + one-time key, calendar override. Defaults to mock mode on :5174 (`E2E_MOCK_PORT` changes it); set `E2E_BASE_URL` (plus `E2E_USER`/`E2E_PASSWORD` to sign in) for a real backend, and `E2E_CHANNEL=chrome` to use the installed Chrome. `make e2e` does all of that against the built jar |
| `npm run icons` | Regenerate `public/` icons (SVG + PNG 192/512/maskable/apple-touch) from `scripts/gen-icons.mjs` |

## Layout

- `src/routes/`: TanStack file routes (§22.2); `src/routeTree.gen.ts` is generated by the router plugin and committed so `tsc` works on a fresh clone.
- `src/app/`: the shells. Phone < 600 has the bottom tab bar and pushed screens. Tablet 600–1023 has the rail, a watchlist drawer and the ticket as a side sheet. Desktop ≥ 1024 has the rail, the watchlist panel, the center, the ticket column and the bottom dock. Routes declare `staticData: { chrome, phone, title }`.
- `src/lib/api/`: `client.ts` (openapi-fetch, CSRF from the `XSRF-TOKEN` cookie, problem details → `ApiError`), `schema.d.ts` (**generated** by `make openapi`, never edited, CI-diffed), `planned.d.ts` (hand-written §18.3 shapes for endpoints whose controllers have not landed yet), `contract.ts` (merges the two: the generated operation or schema always wins; delete planned entries as the backend publishes them), `types.ts` (aliases over the merged contract), `hooks/`, `mock/`. Generated response DTOs follow §18 rule 2: every non-primitive field is `T | null`.
- `src/lib/realtime/`: `RealtimeHub` (ref-counted subscriptions, resubscribe and resync), `stomp.ts` (STOMP over `/ws`, 10 s heartbeats, CSRF in CONNECT), `quoteStore.ts`, `useQuote`, `useUserEvents`.
- `src/lib/format/`: string-decimal math and §22.7 formatting. **Never `parseFloat` money**: oxlint bans the `parseFloat`/`parseInt` globals outside the mock and tests.
- `src/lib/theme/tokens.css`: the §22.8 tokens, exposed to Tailwind as `bg-bg-1`, `text-text-2`, `text-up`, `bg-down-bg`, … Breakpoints are `tablet:` (600), `desktop:` (1024) and `wide:` (1440).
